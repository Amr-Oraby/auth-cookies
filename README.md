# 🔐 Authentication with HTTP-Only Cookies

A simple authentication project built to learn cookie-based authentication and route protection in Next.js.

## What I Learned

- HTTP-only cookie authentication
- Login & logout flow
- Protecting routes using **Client Components**
- Protecting routes using **Server Components** (recommended)
- Sending cookies with `credentials: "include"`
- Reading cookies on the server for secure authentication
- Redirecting unauthorized users

## Tech Stack

- Next.js
- Express.js
- TypeScript
- HTTP-Only Cookies

## Notes

This project was built for learning purposes to understand how modern web applications handle authentication with cookies and why server-side route protection is generally more secure than client-side checks.
